completed repeat, v2 freeze/pair, all source/input fingerprints, actual guarded

receipt. `validate_delivery(path, require_prediction=True)` is stdlib-only and

to reload tensors independently; it verifies the prior actual worker audit,
unchanged tensor bytes and authenticated source/execution evidence. A primary
freeze by itself or a CSV without this completed receipt is not a delivery.

generic once-only submission ledger. Offline prepare creates no API client or
intent. Before a real mutation, validate again in the project interpreter,
require actual whole-team5/UTCday quota, canonical staged CSV and lock/hash/

official full-hash markers or known refs permit read-only recovery. Existing
uploaders/allowlists and all old submission records remain frozen. No module
in this delivery entry imports Kaggle or performs an upload.

