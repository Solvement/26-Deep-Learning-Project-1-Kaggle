# Official development translation probe

Use the two already scored 40k checkpoints, WRN34-3/300 and ResizeMix WRN22-4/160, with their original normalization, frozen weights and BN, native BF16 and one plain forward per view. Use only the same 5,000 official labeled development images in their frozen order. The models differ in training recipe and duration as well as architecture. The 50k model is excluded because its training set overlaps development. The diagnostic does not alter fixed submission inference.

Measure two predeclared input families in separate runs per model. The reflection family uses the original clean image and four signed cardinal offsets at each of 1, 2, 3 and 4 pixels. The canvas family uses the same central 22×22 patch on a fixed RGB training-normalization mean background. Compare its centered baseline and four signed cardinal offsets at each of 2, 3 and 4 pixels. All canvas offsets preserve the exact visible source patch and filler count, though the canvas itself changes the distribution. Canvas is a control for pixels entering or leaving the image and reflection padding, rather than a model of the hidden set.

Within each family and model, report top-1, prediction flips, baseline-correct to shifted-wrong counts and denominators, and per-class slices. Average the four directions per original image before calculating the primary contrast: the accuracy at 2 and 4 pixels averaged, minus accuracy at 3 pixels. Positive means the odd offset is worse than the mean of its adjacent offsets. Also report 4 minus 3, which checks whether the farther aligned shift actually performs better. Use 10,000 paired draws of original images, keeping each image's views together. Intervals describe these fixed checkpoints on reused development images. Separate model executions do not produce a paired between-model interval.

Use one percentage point as the prespecified practical reference. An odd-offset penalty of that size with a positive lower 95% bound in both families supports investigating phase sensitivity. A positive result in reflection alone leaves boundary effects as an alternative. A wider interval that includes a meaningful effect is inconclusive. If both upper bounds fall below one point, deprioritize this specific phase hypothesis. None of these observations alone proves an architectural cause. A future anti-aliasing proposal needs an independent adversarial review and its own matched control before launch.

Keep each run under its own 180-second native guard and the existing shared lease and UTC budget. Save aggregate diagnostics and provenance hashes only. No per-image predictions, labels, IDs, or correctness vectors are persisted. No confirmation or hidden inference, candidate promotion, delivery, or upload.
