This diagnostic asks where the frozen TrivialAugment and WRN34-3/300 classifiers disagree. Both use the same fixed `center80_shift20` inference policy on the 5,000 labeled development images. The two recipes also differ in duration, training precision, and selected weight variant, so differences cannot be attributed to TrivialAugment alone.

Use the six existing cases in order: clean, noise_004, boxblur3, contrast065, brightness080, resize24. Report both-correct, both-wrong, candidate-only-correct, incumbent-only-correct, and accuracy difference for each true class and for all images. The unit of paired analysis is the original image. Keep the same original-image draw across cases in each bootstrap replicate. Report the 95% intervals as descriptive and account for multiple comparisons separately when interpreting the class-by-case results.

Run the exact TA seed-2026 and incumbent checkpoints first. The official development order, transformed pixel hashes and exact correctness marginals must reproduce the frozen benchmark. The two complete correctness-vector hashes must match the original pair receipt. Then compare the completed TA seed-2027 repeat to the same incumbent. Its transformed pixel hashes and correctness counts must match its own benchmark. Same-direction effects across the two TA seeds are a consistency check on these reused development images. They are neither an independent test set nor an estimate of between-seed uncertainty.

Report positive and negative differences symmetrically. A repeatable difference has the same nonzero direction in both comparisons. A training-change hypothesis needs a practically meaningful effect and multiplicity-adjusted evidence, rather than picking the largest unadjusted cell. If the TA disadvantage is diffuse, or only the positive effects repeat, the diagnostic does not justify a targeted change to the incumbent. If a stable weakness is specific to one transformation, propose one intervention with a plausible connection to it and a matched control. The results are diagnostic and leave every existing promotion decision unchanged.
