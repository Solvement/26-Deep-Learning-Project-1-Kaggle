## 第一版固定基线

- CIFAR 适配的三阶段残差 CNN，通道 `[32, 64, 128]`，每阶段 3 个 basic block，3×3 stem，无 ImageNet 风格的大步幅起始下采样。
- **1,084,586 个可训练参数**，运行时强制检查 500 万上限；没有预训练权重加载路径。
- 正式研究从官方 50,000 张训练图像按类别固定 split_seed=42 划分：40,000 训练 / 5,000 开发验证 / 5,000 最终确认。训练 seed 独立于划分 seed；确认集在搜索期间不评估，隐藏 2,000 张仅用于最终推理。此前 45k/5k 工程试跑不参与新比较。
- 随机裁剪/水平翻转；固定 `(x - 0.5) / 0.5` 归一化，不从隐藏评测数据拟合统计量。
- SGD，LR 0.1、momentum 0.9、weight decay 5e-4、label smoothing 0.1、batch 128、5 epoch warmup + cosine、共 120 epoch。CUDA 可用时 AMP。
- GPU 试跑只完成头 5 epoch，保留 120-epoch LR 计划；后续可在相同代码/环境/数据条件下续训。

## 对比顺序

1. 先完成基线，检查数据/标签、训练收敛、验证差距、参数量与耗时。
2. 对比宽度 48 或 64；两者都必须通过实际参数量检查，不能只按配置猜测。
3. 在固定架构下对比增强、label smoothing、weight decay 和训练时长，保留变更与结果记录。
4. 有资源和稳定收益时再考虑更复杂方法。集成的参数预算定义尚未被明确，不在第一版采用。蒸馏的教师也必须从允许数据从零训练。
5. 按固定验证流程选模型；课程目标为至少 80%，争取 90% 以上，实际成绩由实验和官方评测决定。
