# 报告草稿结构（总计不超过 8 页）

来源与期限见 `docs/course-requirements.md`。这是写作结构，不是已完成的实验报告。

1. **第 1 页：标题、成员姓名、公开 GitHub 链接、概述与主要发现。** 链接在交付时必须可公开访问；结果完成前明确标记待填。
2. **第 2–3 页：方法。** 残差架构图、通道/深度/参数量、设计理由、训练和验证划分、增强、优化器/学习率/正则及计算环境。
3. **第 4–5 页：实验与结果。** 基线和受控消融表、训练/验证曲线、实际成本、不同种子或稳定性；明确区分验证分数与官方测试分数。
4. **第 6 页：最终方案与复现。** 最终架构/参数量/官方得分，代码提交、配置、数据版本、训练命令、最佳检查点选择和推理/提交步骤。
5. **第 7 页：讨论、局限与经验。** 哪些改动有效、失败实验、算力限制、泛化和方法取舍。
6. **第 8 页：参考文献。** 图、表与引用全部计入 8 页上限，可按内容调整各节占比。

验收：PDF 页数、所有成员姓名、第一页可访问仓库链接、真实结果与参数量、图表可读性、引用完整、每位队员向 Brightspace 上传。
